# Meu_Jogo_2048

Este é um joguinho simples de codigo aberto.

Como usar:

1. Faça o download dos arquivos clicando em CODIGO baixar zip.
2. Extraia os arquivos no seu computador.
3. Navegue até a pasta do jogo.
4. Execute o index
5. tela do jogo carregada.

Como jogar:

  Clicando nas seta < ^ > v 
  seu objetivo é juntar os numeros iguais até chegar em 2048 onde voce consegue concluir o game,
  mas para isso tem que ter estrategia pois se fizer jogadas erradas e nao conseguir concluir o game terá que
  iniar novamente..

  BOA SORTE!!
